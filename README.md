# NonIID_FL
Mitigating Non-IID Challenges in Federated Learning: A Synthetic Data Augmentation Approach
We implement FL non-IID Synth using Python 3.8.Python was enhanced using the Scikit-learn package and the NumPy, pandas, and synthetic data generation libraries. Our evaluation mainly adopts two metrics: the accuracy of the global model testing and the total communication required between the clients and the server.
